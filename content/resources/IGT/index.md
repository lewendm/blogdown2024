Below is an R script that generates feedback reports on how well students perform an affective decision-making task under uncertainty, namely, the **Iowa Gambling Task (IGT)**. The task has been widely used to test the somatic marker hypothesis (emotional cues that adaptively guide choices).

- 🌐 Source task in PsyToolkit: https://www.psytoolkit.org/experiment-library/igt.html
- 📄 [Example report (PDF)](/resources/IGT_feedbackexample.pdf)
- ‍💻 <a href="/resources/igt_feedback_report.R" download>Download R script</a>
