This report is based on the **Rational–Experiential Inventory (Pacini & Epstein, 1999)** and the **Cognitive Reflection Test**. The code produces a feedback report that summarizes their responses to the CRT, which measures the tendency to override incorrect intuitive responses via deliberation, and REI which measures individuals' general preference for intuition and deliberation. The REI includes two subdimensions for intuitive style and two subdimensinos for analytical/deliberate style. To map these four styles, the code includes a radar/spider chart for the four REI dimensions and places students into one of four quadrants.
